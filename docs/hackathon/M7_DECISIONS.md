# M7 Decisions

- M6 paired state and deltas remain the only numerical authority.
- Two actual `HeartTwinInstance` mounts are used; no CSS clone or screenshot
  duplication is accepted.
- Phase locking synchronizes visual phase only and never overwrites HR.
- Physiologic-rate mode intentionally permits phase drift.
- PV shape is held from the source visualization because M6 lacks pointwise
  paired loop samples; no uncertainty envelope is fabricated.
- Signal context is labeled simulated or unavailable. No measured ECG waveform
  is invented.
- Difference colors/labels communicate simulation direction only, not clinical
  desirability.
- M8 sensitivity, missing-information ranking, and product-navigation redesign
  remain out of scope.
