# M2 performance review

The semantic proxy layer creates one memoized low-resolution sphere per non-functional registry component and uses stable IDs in `userData`. The renderer does not allocate geometry or materials in the pointer callbacks. The shared clock is advanced by one scene-level driver; heart, flow, and electrical layers read the same state.

The existing particle buffer remains bounded at 520 particles. M2 does not add React state updates per animation frame. Browser FPS and WebGL memory should still be checked on the target demo machine because no headless browser profiler is configured in this repository.
