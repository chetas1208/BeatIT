# M7 Component Comparison

Component selection uses the existing semantic registry. The same semantic ID
can be resolved independently in both instances; mesh names never cross the
comparison boundary. Linked selection is enabled by default and focuses the
corresponding component in both panes. Independent selection can be used for
separate inspection.

The inspector displays only values supported by the selected state/registry
binding. AHA and coronary mappings are shown only where existing project
metadata supports them. Missing regional evidence remains unavailable rather
than being inferred from scalar effects.
