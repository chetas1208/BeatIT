# M7 Split Heart Contract

The visual identity is:

```text
same sample ID -> baseline state | scenario state
```

Each pane is a real `HeartTwinInstance`; the right pane is not a CSS clone or a
duplicated screenshot. Both receive explicit state and visualization props.

The transition is user initiated with `Compare this pair`. Pair identity and
scenario provenance are displayed above the panes. Closing comparison returns
to the one-heart surface and does not mutate the trial.

The current procedural heart remains an educational representation of computed
state. It is not a patient-specific finite-element mechanics model.
