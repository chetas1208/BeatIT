# M7 Performance Record

M7 uses two independently mounted canvases because instance isolation is part
of the scientific comparison contract. The comparison clock is centralized;
PV/ECG text and metric panels are downstream consumers.

The performance gate is machine-specific and must record median/p95 frame time,
memory, and any GPU data for single heart, split heart, split plus PV, split
plus signal context, and difference mode. No fixed FPS claim is made without a
measurement. The current environment has not supplied browser frame metrics;
this remains an open completion gate.
