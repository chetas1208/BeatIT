# M10 Scope Freeze

Date: 2026-09-26

## Frozen product

Primary spaces remain exactly:

```text
TWIN
EXPERIMENT
COMPARE
EVIDENCE
REPORT
```

Frozen capabilities:

- interactive semantic heart
- longitudinal twin and timeline
- causal physiology explorer
- probabilistic plausible twins
- same-sample Shadow Trial
- Split Heart comparison
- Missing Piece sensitivity/evidence surface
- provenance and reports
- optional local intelligence runtime

## M10-only changes

Allowed work is limited to audit, integration repair, deployment, health and
readiness, persistence, failure recovery, security, performance measurement,
accessibility verification, deterministic demo packaging, credibility
documentation, and release rehearsal.

No new physiology, uncertainty method, causal method, model capability,
primary navigation space, or major visualization may be added. Existing
deterministic engines and M6/M7/M8 contracts remain authoritative.

## Release claim boundary

The application remains educational simulation software. It is not FDA
validated, clinically validated, regulatory compliant, diagnostic, or a
treatment recommendation system. Synthetic/demo data must remain visibly
labeled.
